# BrickBot
A LEGO brick sorting machine that sorts based on color and size

## Why I Built BrickBot - the problem
- LEGO builders of all ages spend too much time cleaning and sorting their bricks and not enough time building
- LEGO collections in most households are disorganized and just thrown into a bin
- There are no automatic LEGO sorters on the market

## Features
- Color sorting
- Size sorting
- Conveyor belt to move bricks

## Tools Used
- Fusion360
- Arduino IDE

## How to Use
Dump bricks into the holding bin, and BrickBot will take care of the rest! Wait time will vary based on amount of LEGOs
## Results
BrickBot sorts three colors and three sizes
## Future Improvements
- Sort more colors and sizes
- Integrate Brickognize, an online API that can recognize all the different types of LEGOs
- Make the machine stackable (can add more and more sorting layers for faster sorting)
